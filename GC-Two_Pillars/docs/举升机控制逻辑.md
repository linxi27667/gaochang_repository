# 双柱举升机控制逻辑

## IO

| 信号 | 地址 | 类型 | 当前语义 |
| --- | --- | --- | --- |
| 上升按键 | PE0 | 输入 | 按下为 `KEY_PRESS`，点动上升 |
| 下降按键 | PE1 | 输入 | 按下为 `KEY_PRESS`，点动下降 |
| 左柱电源继电器 | PD8 | 输出 | `RELAY_ON` 吸合 |
| 右柱电源继电器 | PD9 | 输出 | `RELAY_ON` 吸合 |
| 上升方向继电器 | PD10 | 输出 | 只允许和下降方向互斥 |
| 下降方向继电器 | PD11 | 输出 | 只允许和上升方向互斥 |
| 上升防撞杆 | PE5/PE6 | 输入 | 默认低电平，触发为高电平 |
| 下降防撞杆 | PE7/PE8 | 输入 | 默认低电平，触发为高电平 |
| 编码器 | TIM1_CH3/CH4 | 输入捕获 | 按当前方向累计左右柱脉冲 |

`Stop_Key` 如果仍出现在 `Core/Inc/main.h` 或 `Core/Src/gpio.c`，属于 CubeMX 生成残留；业务代码不再读取 stop 按键。

## 上电初始化

1. 初始化日志、SPI、W25Q。
2. 读取 W25Q 高度双 slot，选择 CRC 有效且 sequence 最新的一份。
3. `Motor_Init()` 保证电机状态为停止；如果 Flash 已恢复高度，不再清零 `pulse_count`。
4. 初始化安全、按键、编码器，启动 FreeRTOS 任务。

## 按键规则

1. 上升和下降互斥，只有单键按下才允许启动。
2. 双键同时按下是危险输入：
   - 空闲时不启动。
   - 运动中立即急停。
   - 只在冲突状态变化时打印一次日志。
3. 松开当前方向按键立即停止，并触发停机后高度保存流程。

## 防撞杆规则

1. 防撞杆默认低电平；检测到高电平时立即打印一次警告。
2. 上升防撞杆高电平时，禁止继续上升，但允许下降离开。
3. 下降防撞杆高电平时，禁止继续下降，但允许上升离开。
4. 高电平存在时继续请求危险方向，立即急停，进入 `ALARM_COLLISION`，调用蜂鸣器接口并打印警告。
5. `ALARM_COLLISION` 只通过防撞杆输入恢复低电平解除，解除时打印 `A/SAFETY` 日志。

## Flash 高度保存

高度存储使用两个 4KB 扇区轮换：

| slot | 地址 |
| --- | --- |
| A | `0x00002000` |
| B | `0x00003000` |

数据包含 magic、version、sequence、左右柱脉冲和 CRC。运动状态切换为空闲后延时约 200ms 保存一次，保存后回读校验。上电日志会打印 JEDEC ID、Device ID、两个 slot 的有效性和最终加载高度。

## 日志策略

固定心跳日志已删除。现在只在以下事件打印：

- 按键状态变化。
- 方向变化、松手停止、双键冲突。
- 运动中高度变化的节流日志。
- 防撞杆输入变化、危险方向请求、告警解除。
- W25Q 上电扫描、保存、擦写/编程/校验失败。
