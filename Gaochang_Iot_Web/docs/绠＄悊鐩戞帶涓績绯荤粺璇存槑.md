# 高昌举升机管理监控中心系统说明

## 1. 系统定位

本系统用于学校内网环境下统一管理多台举升机，采用浏览器访问方式，不强制依赖公网云平台。系统由三部分组成：

- 设备控制系统：STM32F407 控制器完成升降、限位、失衡保护、报警处理等本地安全闭环。
- 物联网网关：TAS-LTE-892D_s4 DTU 通过 USART3 与 MCU 通信，并通过 MQTT 同步设备状态与管理指令。
- 管理监控中心：Node.js 服务部署于校内服务器或普通 PC，提供 PC/手机浏览器访问界面。

## 2. 功能覆盖

### 系统概览

管理端显示在线、离线、故障、已锁机、待保养设备数量及总运行次数。单台设备卡片显示设备本次上电后的在线时长。

### 设备状态

系统内置不少于 15 台举升机资产台账，每台设备包含设备编号、设备名称、型号、教学区域分组。设备状态支持正常、离线、故障、已锁机、待保养。

### 单机查看

单台设备可查看在线时长、运行次数、机械动作累计时长、当前锁机状态和最近报警状态。

### 运行统计

系统统计设备累计运行次数、平均运行次数，并保留单台设备的在线时长和机械动作累计时长明细。

### 批量操作

支持全部锁机、全部解锁、单台锁机、单台解锁、多选设备锁机/解锁、按教学区域分组锁机/解锁。

### 数字孪生/仿真排故

调试面板支持模拟水平失衡、设备离线、远程锁机、保养到期等典型工况。仿真动作会生成操作日志，便于教学演示。

### 管理员模式

故障解除、管理员点动调平需要先进入管理员模式。MCU 端通过 `admin_enter` 指令校验密码，普通操作员不能直接解除安全报警。

### 维修保养台账

后台支持维修/保养记录新增、查询、导出 CSV。记录字段包括设备名称、设备编号、类型、时间、处理人、处理结果、下次保养日期、备注。

### 操作日志

系统对锁机、解锁、批量操作、管理员模式、故障解除、保养记录、仿真动作生成操作日志，支持按设备、类型、关键字查询。

## 3. 部署方式

进入服务目录：

```powershell
cd E:\MCU\gaochang\code\f407zet6\web_monitor\server
npm install
npm start
```

浏览器访问：

```text
http://服务器IP:8080
```

默认本地账号：

| 账号 | 密码 | 角色 | 权限 |
| --- | --- | --- | --- |
| `admin` | `admin123` | 管理员 | 锁机/解锁、管理员模式、故障解除、资产修改、台账管理 |
| `teacher` | `teacher123` | 教师 | 查看、状态查询、仿真排故、台账新增 |
| `viewer` | `viewer123` | 查看 | 只读查看 |

如使用校内 MQTT Broker：

```powershell
$env:MQTT_URL="mqtt://8.134.167.240:1883"
npm start
```

## 4. 数据存储

系统运行数据保存于：

```text
web_monitor/server/data/devices.json
web_monitor/server/data/logs.json
web_monitor/server/data/maintenance.json
```

该方式便于内网演示和小规模部署。正式项目可平滑替换为 SQLite、MySQL 或 PostgreSQL。
