## FRAM 存储（已替代全部 W25Q 落盘）

芯片：FM24CL64B **8KB**，I2C1 PB6/PB7；API 名仍为 `App_W25Qxx_*`。  
`W25Q_Sector_Erase` = 从地址起写 **256×0xFF**（journal 回收依赖此语义）。双槽间距 **256**。自检区 **0x1FF0** 勿占。

| 产品 | 落盘内容 |
|------|----------|
| 丝杆 | Storage + Height |
| 双柱 | Storage/Config/Stats/OpLog + Rise Journal + Maint Ledger |
| 大剪 | Storage/Config/Stats/OpLog + RiseQueue + Maintenance |
| 小剪 | Storage/Config/Stats/OpLog + RiseCounter + Maintenance |
| 超薄 | Storage/Config/Stats/OpLog + RiseStats + Maintenance |

容量相对 F407(W25Q) 更小（条数按 8KB 压缩），语义对齐。
