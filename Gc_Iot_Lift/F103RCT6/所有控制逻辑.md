# 高昌举升机控制逻辑总览（F103RCT6 版）

本文按 F103RCT6（类PLC控制板_2）五个固件项目源码整理控制逻辑，为 `F407ZET6/所有控制逻辑.md` 的 F103 对应版本。业务逻辑与 F407 一比一移植（已逐文件 diff 验证），差异仅限板级通道映射、存储介质与串口通道。

更新日期：2026-09-06

## 0. F103RCT6 平台差异（相对 F407）

| 项 | F407ZET6 | F103RCT6 |
|---|---|---|
| 主控/时钟 | F407ZET6 @168MHz | F103RCT6 @72MHz（HSE 8MHz × PLL9） |
| 输入 | 直连 GPIO，按键低有效/限位高有效 | 10 路光耦隔离（24V），MCU 侧统一低有效，io_map 归一化 |
| 输出 | PF8/PF9/PD8-PD11 等 | RELAY0–5 干接点（PB12–15/PC6/PC7）+ OUT0–3 24V MOSFET（PC3/PC2/PC1/PC0） |
| 存储 | W25Qxx SPI Flash | FM24CL64 FRAM（I2C1 PB6/PB7），保留 W25Q API 名 |
| DTU 串口 | USART3（带 RS485_DE） | USART1（PA9/PA10，无 RS485_DE） |
| 编码器 | TIM1 CH3/CH4（PE13/PE14） | TIM4 CH3/CH4（PB8/PB9，仅丝杆使用） |
| 芯片 UID | 0x1FFF7A10 | 0x1FFFF7E8 |
| DTU 任务栈 | 4096 | 2048（RAM 限制） |

## 1. 公共规则

### 1.1 安全优先级

所有固件都遵循"先安全、后动作、最后输出"的原则：

1. 急停、远程锁定、光电报警、非法按键组合、故障状态优先级最高。
2. 任一安全保护触发时，运动输出立即关闭。
3. 补油不能绕过急停、光电、远程锁定、故障和非法组合。
4. 物联网上报统一限速为约 1 秒 1 包：周期 telemetry、运动中高度包、事件包都使用 1000ms 间隔。

### 1.2 补油规则

补油只在带补油按钮的剪式举升机中有效：

```text
补油有效条件：
  上升按钮按下
  补油按钮按下
  下降按钮未按下
  锁定按钮未按下

补油按钮单独按下：
  不启动任何动作

补油与普通上升的主要差异：
  普通上升受上限位限制
  补油忽略上限位
```

## 2. 大剪固件 `GC_Big_Scissor`

### 2.1 项目角色

大剪支持主机/子机角色，旋转开关选择当前角色。角色切换时立即关闭所有输出并回到空闲。

### 2.2 输入输出

输入（光耦输入，闭合触发，软件归一化 1=触发）：

| 功能 | 板上端子 | MCU 引脚 |
|---|---|---|
| 上升 | IN0 | PA1 |
| 下降 | IN1 | PA2 |
| 锁定 | IN2 | PA3 |
| 急停 | IN3 | PA4 |
| 主机上限位 | IN4 | PA5 |
| 主机下限位 | IN5 | PA6 |
| 补油 | IN6 | PA7 |
| 光电 | IN7 | PC4 |
| 旋转开关 | IN8 | PC5（闭合=主机/断开=子机） |
| 子机上限位 | IN9 | PB0 |

输出：

| 功能 | 板上端子 | MCU 引脚 | 电气 |
|---|---|---|---|
| Y0 电机 | RELAY0 | PB12 | 干接点 |
| Y1 下降阀 | OUT0 | PC3 | 24V MOSFET |
| Y2 主机气阀 | OUT1 | PC2 | 24V MOSFET |
| Y3 主机工作阀 | OUT2 | PC1 | 24V MOSFET |
| Y4 子机气阀 | OUT3 | PC0 | 24V MOSFET |
| Y5 子机工作阀 | RELAY1 | PB13 | 干接点（OUT 仅 4 路） |

### 2.3 动作逻辑

上升：

```text
空闲 + 上升按下 + 当前角色上限位未触发：
  电机 ON
  当前角色工作阀 ON
  延时 motor_to_valve_delay_ms 后当前角色气阀 ON

停止条件：
  上升按钮释放
  当前角色上限位触发
  安全保护触发
```

下降：

```text
空闲 + 下降按下：
  电机 ON
  当前角色工作阀 ON
  延时 motor_to_valve_delay_ms 后当前角色气阀 ON
  再保持当前角色 motor_hold_ms
  电机 OFF
  下降阀 ON
  当前角色工作阀/气阀保持 ON

主机下限位触发：
  立即全停回空闲

下降按钮释放：
  全停回空闲
```

锁定：

```text
空闲 + 锁定按下：
  当前角色工作阀 ON
  下降阀 ON
  电机 OFF
  气阀 OFF

锁定按钮释放：
  全停回空闲
```

补油：

```text
空闲 + 上升按下 + 补油按下：
  电机 ON
  当前角色工作阀 ON
  延时 motor_to_valve_delay_ms 后当前角色气阀 ON
  不检查当前角色上限位

任一按钮释放：
  全停回空闲
```

## 3. 两柱固件 `GC-Two_Pillars`

### 3.1 项目角色

该工程用于两柱举升机。两柱模式无补油、无光电。

### 3.2 输入输出

输入：

| 功能 | 板上端子 | MCU 引脚 |
|---|---|---|
| 上升 | IN0 | PA1 |
| 下降 | IN1 | PA2 |
| 锁定 | IN2 | PA3 |
| 急停 | IN3 | PA4 |
| 上限位 | IN4 | PA5 |

输出：

| 功能 | 板上端子 | MCU 引脚 | 电气 |
|---|---|---|---|
| 电机 | RELAY0 | PB12 | 干接点 |
| 电磁铁 | OUT0 | PC3 | 24V MOSFET |
| 下降阀 | OUT1 | PC2 | 24V MOSFET |

### 3.3 动作逻辑

上升：

```text
空闲 + 上升按下 + 上限位未触发：
  电机 ON

停止条件：
  上升按钮释放
  上限位触发
```

下降：

```text
空闲 + 下降按下：
  电机 ON
  200ms 后电磁铁 ON
  电机累计运行到 2000ms 后：
    电机 OFF
    下降阀 ON
    电磁铁保持 ON

如果下降过程中上限位触发或锁定按钮按下：
  电机 OFF
  电磁铁 ON
  进入强制解锁等待
  到 2000ms 后下降阀 ON

下降按钮释放：
  全停回空闲
```

锁定：

```text
空闲 + 锁定按下：
  下降阀 ON
  电机 OFF
  电磁铁 OFF

锁定按钮释放：
  全停回空闲
```

## 4. 小剪固件 `GC_Small_Scissor`

### 4.1 输入输出

输入：

| 功能 | 逻辑名 | 板上端子 | MCU 引脚 |
|---|---|---|---|
| 上升 | up | IN0 | PA1 |
| 下降 | down | IN1 | PA2 |
| 锁定 | lock | IN2 | PA3 |
| 急停 | estop | IN3 | PA4 |
| 补油 | refill | IN4 | PA5 |
| 上限位 | upper | IN5 | PA6 |
| 下限位 | lower | IN6 | PA7（同时用于屏蔽光电） |
| 光电 | photo | IN7 | PC4 |

输出：

| 功能 | 板上端子 | MCU 引脚 | 电气 |
|---|---|---|---|
| 电机 | RELAY0 | PB12 | 干接点 |
| 下降阀 | OUT0 | PC3 | 24V MOSFET |
| 气阀 | OUT1 | PC2 | 24V MOSFET |

### 4.2 状态机

小剪使用集中式状态机：采集输入、前置安全检查、状态切换、输出仲裁、最终安全闸门、硬件输出。

上升：

```text
空闲 + 上升按下 + 上限位未触发：
  电机 ON
  200ms 后气阀 ON
  下降阀 OFF

上升按钮释放或上限位触发：
  全停回空闲
```

下降：

```text
空闲 + 下降按下：
  down_prepare: 电机 ON
  200ms 后进入 down_hold_motor: 电机 ON + 气阀 ON
  气阀打开后保持 3000ms
  dropping: 电机 OFF + 下降阀 ON + 气阀 ON

上限位触发或锁定按钮按下：
  直接进入 dropping

下降按钮释放：
  全停回空闲
```

锁定：

```text
空闲 + 锁定按下：
  下降阀 ON
  气阀 ON
  电机 OFF

锁定按钮释放：
  全停回空闲
```

补油：

```text
空闲 + 上升按下 + 补油按下：
  电机 ON
  200ms 后气阀 ON
  下降阀 OFF
  不检查上限位

上升/补油任一释放，或下降/锁定介入：
  全停回空闲
```

安全：

```text
远程锁定：
  运动中转 safe_stop，输出全关

急停：
  输出全关，进入 estop；急停释放且按钮释放后回空闲

光电：
  下限位触发时屏蔽光电
  运动中触发光电需要远程清报警
  非运动触发光电可在光电恢复且按钮释放后自动清除

上升+下降同时按下：
  进入 safe_stop，输出全关

超时：
  上升/下降超过 60s 进入 fault
```

|---|---|---|
| 上升 | IN0 | PA1 |
| 下降 | IN1 | PA2 |
| 锁定 | IN2 | PA3 |
| 急停 | IN3 | PA4 |
| 补油 | IN4 | PA5 |
| 上限位 | IN5 | PA6 |
| 下限位 | IN6 | PA7 |

输出：

| 功能 | 板上端子 | MCU 引脚 | 电气 |
|---|---|---|---|
| 电机 | RELAY0 | PB12 | 干接点 |
| 下降阀 | OUT0 | PC3 | 24V MOSFET |
| 气阀 | OUT1 | PC2 | 24V MOSFET |

### 5.2 动作逻辑

上升：

```text
空闲 + 上升按下 + 上限位未触发：
  电机 ON
  下降阀 OFF
  气阀 OFF

上升按钮释放或上限位触发：
  全停回空闲
```

下降：

```text
空闲 + 下降按下：
  电机 ON

达到 motor_to_valve_delay_ms：
  气阀 ON

达到 motor_hold_ms：
  电机 OFF
  下降阀 ON

上限位触发或锁定按钮按下：
  电机 OFF
  下降阀 ON
  气阀 ON

下限位触发：
  电机 OFF
  下降阀 ON
  气阀 OFF

下降按钮释放：
  全停回空闲
```

锁定：

```text
空闲 + 锁定按下：
  电机 OFF
  下降阀 ON
  气阀 OFF

锁定按钮释放：
  全停回空闲
```

补油：

```text
空闲 + 上升按下 + 补油按下：
  电机 ON
  下降阀 OFF
  气阀 OFF
  不检查上限位

上升/补油任一释放，或下降/锁定介入：
  全停回空闲
```

安全：

```text
上升+下降同时按下：
  如果正在动作则全停；空闲时保持输出全关

急停、光电、远程锁定：
  由 lift_core 公共安全层处理，触发时输出全关

下限位：
  下降时强制气阀 OFF，避免反挺
  锁定时气阀始终 OFF
  静止落地时屏蔽光电的正常遮挡；运动中光电始终触发全停
```

## 6. 丝杆固件 `GC-Screw_Lift`（F103 新增章节）

### 6.1 输入输出

输入：

| 功能 | 板上端子 | MCU 引脚 | 说明 |
|---|---|---|---|
| 上升键 | IN0 | PA1 | 点动 |
| 下降键 | IN1 | PA2 | 点动 |
| 停止键（预留） | IN2 | PA3 | 宏保留，业务不读 |
| 左上防撞 | IN3 | PA4 | EXTI 下降沿即停 |
| 右上防撞 | IN4 | PA5 | EXTI 下降沿即停 |
| 左下防撞 | IN5 | PA6 | EXTI 下降沿即停 |
| 右下防撞 | IN6 | PA7 | EXTI 下降沿即停 |

输出：

| 功能 | 板上端子 | MCU 引脚 |
|---|---|---|
| 左电机电源 | RELAY0 | PB12 |
| 右电机电源 | RELAY1 | PB13 |
| 上升方向 | RELAY2 | PB14 |
| 下降方向 | RELAY3 | PB15 |

编码器：左列 PB8（TIM4_CH3）、右列 PB9（TIM4_CH4），下降沿计数。

### 6.2 动作逻辑

```text
上升键按下：
  上升方向继电器 ON + 左右电机电源继电器 ON
  编码器按上升方向累计脉冲

下降键按下：
  下降方向继电器 ON + 左右电机电源继电器 ON
  编码器按下降方向递减脉冲

按键释放 / 防撞触发 / 安全条件不满足：
  全部继电器 OFF

防撞（四路，EXTI 下降沿）：
  任一防撞输入触发立即停机，进入碰撞报警，
  需防撞恢复并清报警后方可再次动作

双柱平衡：
  两列编码器差值超限时暂停超前侧电机，
  等待 balance_wait_max_ms 超时报警

测高：
  脉冲数 × 丝杆导程 8mm 换算高度，掉电保存
```

## 7. Web 管理端 `Gaochang_Iot_Web`

Web 端负责 MQTT 接入、设备管理、命令下发、报警/维修/日志/统计展示（与 F407 共用同一 Web 端）。

MQTT（v1，按芯片 UID 寻址）：

```text
Broker: mqtt://mqtt.gclift.net:1883
设备 ClientId: gc-lift-<UID>
Telemetry: gaochang/lift/v1/devices/<UID>/telemetry
Command:   gaochang/lift/v1/devices/<UID>/command
Status:    gaochang/lift/v1/devices/<UID>/status
```

主要命令：

| 命令 | 作用 |
|---|---|
| lock / unlock | 远程锁机 / 解锁 |
| get_status | 查询设备状态 |
| clear_alarm | 清除报警 |
| rename | 修改设备名称 |
| set_config / get_config | 下发/读取参数 |
| set_product_type | 切换产品类型 |
| buzzer_on / buzzer_off | 控制蜂鸣器 |

## 8. 文件与调试约定

1. `APP/Src` 放产品状态机、IoT JSON、DTU 协议、存储和业务逻辑。
2. `Driver/Src` 放 FreeRTOS 任务封装、周期调度和硬件驱动门面。
3. `Core/Src`、`BSP`、`Drivers`、`Middlewares` 保留 CubeMX/HAL/FreeRTOS/BSP 代码。
4. `RTT_easylog` 是日志库源码，不是运行日志，不应删除。
5. `*.log`、`rtt_capture*.txt`、`rtt_logger*.txt`、`jlink_*.txt` 属于临时构建/调试输出，可以清理。
6. 存储统一走 `App_W25Qxx_*` API（底层 FRAM），勿直接调用 I2C。
7. 板级引脚映射冻结于 `docs/F103RCT6_移植引脚与真机检查单.md`，后续业务复刻不再改引脚。
