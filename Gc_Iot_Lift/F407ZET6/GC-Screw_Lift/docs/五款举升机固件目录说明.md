# 五款举升机固件目录说明

迁移后的 `GC-Screw_Lift` 目录用于集中保存举升机固件和 F407ZET6 丝杆举升机的接线、控制与平台接入资料。

| 目录 | 产品类型 | 说明 |
| --- | --- | --- |
| 根目录 | `GC-Screw_Lift` | STM32F407 双柱丝杆举升机固件、CubeMX、Keil 工程和文档 |
| `GC-Two_Pillars` | `double_post` | 原两柱举升机固件参考实现 |
| `GC_Big_Scissor` | `large_scissor` | 大剪举升机固件 |
| `GC_Small_Scissor` | `small_scissor` | 小剪举升机固件 |
| `GC_Thin_Scissor` | `thin_scissor` | 超薄小剪举升机固件 |

各机型仍是独立固件工程，不能交叉复制 GPIO、驱动或运动控制代码。共用的 MQTT v1 协议以芯片 UID 和 `product_type` 隔离，平台必须按实际机型登记。
