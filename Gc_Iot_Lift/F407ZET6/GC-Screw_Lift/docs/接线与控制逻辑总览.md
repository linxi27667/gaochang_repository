# GC-Screw_Lift（F407ZET6）丝杆举升机接线与控制逻辑总览

本文件以当前 `Core/Inc/main.h`、CubeMX 生成代码及 APP/Driver 逻辑为准。原始硬件资料 `高昌机电_多功能控制板_硬件设计计划书_V1.0.docx/.pdf` 保留在本目录，接线变更应同时更新 CubeMX 配置、本文档和硬件图纸。

## 控制与安全接线

| 功能 | MCU 信号 | 电平/模式 | 固件行为 |
| --- | --- | --- | --- |
| 上升按键 | PE0 | 上拉输入，低有效 | 单独按下时请求上升；松开即停机 |
| 下降按键 | PE1 | 上拉输入，低有效 | 单独按下时请求下降；松开即停机 |
| 左柱电机电源 | PD8 | 推挽输出，高电平吸合 | 左柱电机总电源继电器 |
| 右柱电机电源 | PD9 | 推挽输出，高电平吸合 | 右柱电机总电源继电器 |
| 上升方向 | PD10 | 推挽输出，高电平吸合 | 与 PD11 互斥 |
| 下降方向 | PD11 | 推挽输出，高电平吸合 | 与 PD10 互斥 |
| 左上防撞杆 | PE5 | 下拉输入，EXTI 上升沿 | 仅禁止上升；中断内立即切断电机 |
| 右上防撞杆 | PE6 | 下拉输入，EXTI 上升沿 | 仅禁止上升；中断内立即切断电机 |
| 左下防撞杆 | PE7 | 下拉输入，EXTI 上升沿 | 仅禁止下降；中断内立即切断电机 |
| 右下防撞杆 | PE8 | 下拉输入，EXTI 上升沿 | 仅禁止下降；中断内立即切断电机 |
| 左柱编码器 | PE13 / TIM1_CH3 | 输入捕获，下降沿 | 记录左柱脉冲 |
| 右柱编码器 | PE14 / TIM1_CH4 | 输入捕获，下降沿 | 记录右柱脉冲 |
| W25Q Flash 片选 | PB6 | 推挽输出，高有效空闲 | 双 slot 保存左右高度与 CRC |
| 运行/通信/电源指示 | PG2 / PG3 / PG4 | 推挽输出，低电平点亮 | 状态指示用途 |

`Stop_Key`（PE2）是 CubeMX 遗留输入，当前业务控制逻辑不读取该信号；不能把它当作安全急停。急停/接触器等最终人身安全回路必须由独立硬件实现。

## 4G DTU 接线

| 功能 | MCU 信号 | 配置 |
| --- | --- | --- |
| DTU / RS485 发送 | PB10 / USART3_TX | 9600, 8N1 |
| DTU / RS485 接收 | PB11 / USART3_RX | DMA 循环接收 |
| 485 收发方向 | PD0 | 由 BSP 在发送与接收间切换 |
| 调试串口发送 | PC6 / USART6_TX | 115200, 8N1 |
| 调试串口接收 | PC7 / USART6_RX | DMA 循环接收 |

上电前必须确认 DTU 与控制板共地、TX/RX 方向匹配、RS485 A/B 极性匹配，并且 DTU 供电满足模块峰值电流。不得把 3.3V MCU 引脚直接接至不兼容的 5V 逻辑口。

## 运动与安全顺序

1. 上升和下降按键互斥；两个方向同时按下不启动，运行中发生冲突立即停止。
2. 启动时先设置唯一的方向继电器，再接通柱电源；停机时先断柱电源，再断方向继电器。
3. 任一防撞杆上升沿触发时，EXTI 只做紧急断电和方向置停止；日志、蜂鸣器接口及云端状态由任务上下文后续处理。
4. 上方防撞仅阻止上升，下方防撞仅阻止下降；脱离危险方向后可反向离开。
5. 编码器按当前方向累计，安全层持续检查高度上限、下限、失速与左右同步。当前标定为 `1 脉冲 = 8 mm`，软件最大高度为 `1000 mm`；实际设备投入前必须用实机行程重新核定该换算与限位。
6. 锁机命令、管理员点动和清故障仍调用既有 `Motor_*` 与 `Safety_*` 接口，云端不会绕过防撞、限位、同步或权限检查。

## 物联网控制边界

GC-Screw_Lift 接入 v1 MQTT 平台，支持状态查询、锁机/解锁、管理员进入/退出、管理员点动、故障清除、DTU 重配与重启。每条下行命令必须携带本机 `target_uid` 和 `msg_id`；重复 `msg_id` 只重发回执，不会重复驱动电机。

本硬件当前没有可用蜂鸣器驱动实现，也没有剪式机使用的远程运动参数配置或使用次数 Flash 账本。因此平台登记时应保持 `has_buzzer=0`，并且不应向本设备下发 `buzzer_on`、`buzzer_off`、`set_config`、`get_config` 或 `reset_usage`。这些限制是为了防止平台把其他机型的控制能力误用于丝杆举升机。

## 上线验收

1. 不接负载时，确认所有继电器的停止态为断开，方向继电器不会同时吸合。
2. 分别触发 PE5、PE6、PE7、PE8，确认危险方向立即断电、反方向仍可退出。
3. 分别验证 PE13 和 PE14 编码器脉冲及左右高度差。
4. DTU 上线后，从上行 JSON 记录 `chip_uid`，在平台登记为 `double_post` 并绑定目标设备。
5. 验证 `get_status`、`lock`、`unlock` 的命令回执都以相同 `msg_id` 闭环；重复发布同一命令不得重复执行。
