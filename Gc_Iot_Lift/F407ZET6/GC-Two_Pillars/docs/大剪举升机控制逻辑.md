## 一、I/O 点位表

## 二、电平逻辑速查表

> **重要**：控制器的输入读取值（0 或 1）和"动作是否发生"的关系必须区分清楚。

### 2.1 输入电平对照

| 点号 | 名称 | 物理状态 | 控制器读到 | 含义 |
|------|------|----------|------------|------|
| X0 | 上升按钮 | 按下（接通 GND） | **0** | 上升命令有效 |
| X0 | 上升按钮 | 未按（上拉） | **1** | 无上升命令 |
| X1 | 下降按钮 | 按下（接通 GND） | **0** | 下降命令有效 |
| X1 | 下降按钮 | 未按（上拉） | **1** | 无下降命令 |
| X2 | 锁定按钮 | 按下（接通 GND） | **0** | 锁定命令有效 |
| X2 | 锁定按钮 | 未按（上拉） | **1** | 无锁定命令 |
| X3 | 急停按钮 | 按下（NC 断开） | **1** | 急停触发 |
| X3 | 急停按钮 | 未按（NC 闭合到 GND） | **0** | 无急停 |
| X4 | 上限位 | 到顶（NC 断开） | **1** | 上限位触发 |
| X4 | 上限位 | 未到顶（NC 闭合到 GND） | **0** | 未到顶 |

| X5 | 补油按钮 | 未按（上拉） | **1** | 无补油命令 |
| X6 | 光电开关 | 被遮挡（输出高） | **1** | 报警触发 |
| X6 | 光电开关 | 未遮挡（输出低） | **0** | 无报警 |
| X7 | 旋转开关 | 主机档（接通 VCC） | **1** | 主机模式 |
| X7 | 旋转开关 | 子机档（断开到 GND） | **0** | 子机模式 |

### 2.2 输出电平对照

| 点号 | 名称 | 输出值 | 物理状态 | 含义 |
|------|------|--------|----------|------|
| Y0 | 电机继电器 | **1** | 输出高电平，继电器吸合 | 电机运行 |
| Y0 | 电机继电器 | **0** | 输出低电平，继电器断开 | 电机停止 |
| Y1 | 下降阀 | **1** | 输出高电平，电磁阀得电 | 下降阀打开 |
| Y1 | 下降阀 | **0** | 输出低电平，电磁阀失电 | 下降阀关闭 |
| Y2 | 主机气阀 | **1** | 输出高电平，电磁阀得电 | 主机气阀打开 |
| Y2 | 主机气阀 | **0** | 输出低电平，电磁阀失电 | 主机气阀关闭 |
| Y3 | 主机工作阀 | **1** | 输出高电平，电磁阀得电 | 主机工作阀打开 |
| Y3 | 主机工作阀 | **0** | 输出低电平，电磁阀失电 | 主机工作阀关闭 |
| Y4 | 子机气阀 | **1** | 输出高电平，电磁阀得电 | 子机气阀打开 |
| Y4 | 子机气阀 | **0** | 输出低电平，电磁阀失电 | 子机气阀关闭 |
| Y5 | 子机工作阀 | **1** | 输出高电平，电磁阀得电 | 子机工作阀打开 |
| Y5 | 子机工作阀 | **0** | 输出低电平，电磁阀失电 | 子机工作阀关闭 |

### 2.3 归一化说明

> 为简化伪代码，本文件中 **X0~X7 的值统一表示"动作是否发生"**：
> - **X=1**：表示该输入对应的动作发生（按钮按下 / 急停触发 / 上限位触发 / 光电遮挡 / 主机档）
> - **X=0**：表示该输入对应的动作未发生
>
> 控制器内部已做归一化处理，伪代码中 **X0=1 即代表上升按钮按下**（虽然物理读到的是 0V）。
>
> **Y0~Y5 的值**：1=接通（高电平），0=断开（低电平）。

## 三、主程序框架（10ms 周期扫描）

```
主循环（每 10ms 执行一次）:

    ===== 第一步：急停检测（最高优先级）=====
    如果 X3=1（急停按下，NC断开，控制器读到高电平1）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部输出低电平，断开所有阀和电机）
        状态 = "急停"
        上报急停事件
        本周期结束，直接返回

    如果 X3=0（急停未按，NC闭合到GND，控制器读到低电平0）且 状态=="急停":
        状态 = "空闲"（急停释放自动恢复）

    ===== 第二步：光电报警检测 =====
    如果 X6=1（光电被遮挡，输出高电平1）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部输出低电平，断开所有阀和电机）
        状态 = "光电报警"
        上报光电报警事件
        本周期结束，直接返回

    ===== 第三步：光电报警锁定 =====
    如果 状态=="光电报警":
        本周期结束，直接返回
        （即使 X6=0 光电已恢复，也必须等后台远程发"解除报警"命令才能继续动作）

    ===== 第四步：远程锁定检测 =====
    如果 远程锁定标志=1:
        本周期结束，直接返回
        （后台远程锁定时，所有按钮失效）

    ===== 第五步：执行大剪控制逻辑 =====
    调用 大剪控制子程序()
```

## 四、大剪控制子程序

### 4.1 旋转开关切换检测

```
判断旋转开关 X7:
    如果 X7=1（旋转开关打到主机档，接通VCC，控制器读到高电平1）:
        当前角色 = 主机
    如果 X7=0（旋转开关打到子机档，断开到GND，控制器读到低电平0）:
        当前角色 = 子机

如果 当前角色 与 上次角色不同:
    Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部输出低电平，断开所有阀和电机）
    状态 = "空闲"
    记录"旋转开关切换"日志
    本周期结束，返回
```

### 4.2 空闲状态按钮扫描

```
如果 状态 == "空闲":
    优先级1：补油（上升+补油同时按）
    如果 X0=1（上升按钮按下，接通GND，归一化为1） 且 X5=1（补油按钮按下，接通GND，归一化为1）:
        启动补油流程()

    优先级2：上升
    否则如果 X0=1（上升按钮按下，归一化为1，上升沿触发）:
        启动上升流程()

    优先级3：下降
    否则如果 X1=1（下降按钮按下，接通GND，归一化为1，上升沿触发）:
        启动下降流程()

    优先级4：锁定
    否则如果 X2=1（锁定按钮按下，接通GND，归一化为1，上升沿触发）:
        启动锁定流程()
```

> **上升沿说明**：按钮从"未按下（X=0）"变为"按下（X=1）"的那个扫描周期才触发，防止长按重复启动。

## 五、四个动作流程详解

### 5.1 主机上升流程

```
启动上升流程（主机）:
    Y0=1（电机继电器输出高电平，电机运行）
    Y3=1（主机工作阀输出高电平，工作阀打开）
    启动延时定时器 T1=200ms
    状态 = "上升等待气阀"
    记录"上升开始"日志，角色=主机
    累计主机上升次数 +1

上升等待气阀状态处理:
    如果 T1 到时（200ms 已过）:
        Y2=1（主机气阀输出高电平，气阀打开）
        状态 = "上升运行中"

上升运行中状态处理:
    如果 X4=1（上限位触发，NC断开，控制器读到高电平1）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部断开）
        状态 = "空闲"
        记录"上升停止-上限位"

    如果 X0=0（上升按钮释放，上拉为高电平，归一化为0）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部断开）
        状态 = "空闲"
        记录"上升停止-按钮释放"
```

### 5.2 主机下降流程

```
启动下降流程（主机）:
    Y0=1（电机继电器输出高电平，电机运行）
    Y3=1（主机工作阀输出高电平，工作阀打开）
    启动延时定时器 T1=200ms
    状态 = "下降阶段1"
    记录"下降开始"日志，角色=主机
    累计主机下降次数 +1

下降阶段1 处理（等气阀延时）:
    如果 T1 到时（200ms）:
        Y2=1（主机气阀输出高电平，气阀打开）
        启动延时定时器 T2=3000ms（主机电机保持时间）
        状态 = "下降阶段2"

下降阶段2 处理（等电机保持时间）:
    如果 T2 到时（3000ms）:
        Y0=0（电机继电器输出低电平，电机停止）
        Y1=1（下降阀输出高电平，下降阀打开）
        状态 = "下降卸载中"

下降卸载中状态处理:
    ===== 强制下降条件（注意：不是停止！）=====
    如果 X4=1（上限位触发，NC断开，读到高电平1）
       或 X2=1（锁定按钮按下，接通GND，归一化为1）:
        Y0=0（电机继电器输出低电平，电机停止）
        Y2=1（主机气阀输出高电平，气阀打开）
        Y3=1（主机工作阀输出高电平，工作阀打开）
        Y1=1（下降阀输出高电平，下降阀打开）
        状态 = "下降卸载中"
        （继续下降，不停止）

    如果 X1=0（下降按钮释放，上拉为高电平，归一化为0）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部断开）
        状态 = "空闲"
        记录"下降停止-按钮释放"
```

> **重要**：下降过程中，上限位触发或锁定按钮按下时，**不是停止**，而是"强制下降"——电机断开，所有阀打开，加速卸载。这是举升机安全设计。

### 5.3 主机锁定流程

```
启动锁定流程（主机）:
    Y3=1（主机工作阀输出高电平，工作阀打开）
    Y1=1（下降阀输出高电平，下降阀打开）
    状态 = "锁定保持"
    记录"锁定开始"日志

锁定保持状态处理:
    如果 X2=0（锁定按钮释放，上拉为高电平，归一化为0）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部断开）
        状态 = "空闲"
        记录"锁定停止"
```

### 5.4 主机补油流程

```
启动补油流程（主机）:
    Y0=1（电机继电器输出高电平，电机运行）
    Y3=1（主机工作阀输出高电平，工作阀打开）
    Y2=1（主机气阀输出高电平，气阀打开）
    状态 = "补油中"
    记录"补油开始"日志

补油中状态处理:
    如果 X0=0（上升按钮释放，归一化为0）
       或 X5=0（补油按钮释放，归一化为0）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部断开）
        状态 = "空闲"
        记录"补油停止"
```

## 六、子机流程（与主机差异点）

### 6.1 子机上升

```
启动上升流程（子机）:
    Y0=1（电机继电器输出高电平，电机运行）
    Y5=1（子机工作阀输出高电平，工作阀打开）
    ★ Y4=0 子机气阀保持低电平，不开气阀 ★
    状态 = "上升运行中"（直接进入，无需等气阀）

子机上升运行中:
    如果 X4=1（上限位触发，NC断开，读到高电平1）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部断开）
        回空闲
    如果 X0=0（上升按钮释放，归一化为0）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部断开）
        回空闲
```

### 6.2 子机下降

```
启动下降流程（子机）:
    Y0=1（电机继电器输出高电平，电机运行）
    Y5=1（子机工作阀输出高电平，工作阀打开）
    启动 T1=200ms
    状态 = "下降阶段1"

下降阶段1:
    如果 T1 到时（200ms）:
        Y4=1（子机气阀输出高电平，气阀打开）
        启动 T2=1500ms（★ 子机保持时间比主机短 ★）
        状态 = "下降阶段2"

下降阶段2:
    如果 T2 到时（1500ms）:
        Y0=0（电机继电器输出低电平，电机停止）
        Y1=1（下降阀输出高电平，下降阀打开）
        状态 = "下降卸载中"

下降卸载中:
    强制下降条件同主机（X4=1 上限位 或 X2=1 锁定按钮）:
        Y0=0（电机断开）
        Y4=1（子机气阀打开）
        Y5=1（子机工作阀打开）
        Y1=1（下降阀打开）
    如果 X1=0（下降按钮释放，归一化为0）:
        全部断开，回空闲
```

### 6.3 子机锁定

```
启动锁定流程（子机）:
    Y5=1（子机工作阀输出高电平，工作阀打开）
    Y1=1（下降阀输出高电平，下降阀打开）
    状态 = "锁定保持"

锁定保持:
    如果 X2=0（锁定按钮释放，归一化为0）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部断开）
        回空闲
```

### 6.4 子机补油

```
启动补油流程（子机）:
    Y0=1（电机继电器输出高电平，电机运行）
    Y5=1（子机工作阀输出高电平，工作阀打开）
    ★ Y4=0 子机气阀保持低电平，不开气阀 ★
    状态 = "补油中"

补油中:
    如果 X0=0（上升按钮释放，归一化为0）
       或 X5=0（补油按钮释放，归一化为0）:
        Y0=0, Y1=0, Y2=0, Y3=0, Y4=0, Y5=0（全部断开）
        回空闲
```

## 七、主/子机差异对照表

| 动作 | 主机输出 | 子机输出 |
|------|----------|----------|
| 上升气阀 | Y2=1（主机气阀打开，延时200ms） | **Y4=0（子机气阀不开）** |
| 下降电机保持时间 | T2=3000ms | **T2=1500ms** |
| 下降气阀 | Y2=1（主机气阀打开） | Y4=1（子机气阀打开） |
| 锁定阀 | Y3=1（主机工作阀）+ Y1=1（下降阀） | Y5=1（子机工作阀）+ Y1=1（下降阀） |
| 补油气阀 | Y2=1（主机气阀打开） | **Y4=0（子机气阀不开）** |
| 上升/补油工作阀 | Y3=1（主机工作阀） | Y5=1（子机工作阀） |

## 八、安全保护优先级（从高到低）

| 优先级 | 信号 | 点号 | 触发电平 | 动作 | 恢复方式 |
|--------|------|------|----------|------|----------|
| 1 | 急停 | X3 | 高有效（按下=1） | 立即全停 | **自动恢复**（急停释放即可） |
| 2 | 光电 | X6 | 高有效（遮挡=1） | 立即全停 | **必须后台远程解除** |
| 3 | 远程锁定 | 软标志 | — | 按钮全失效 | 后台远程解锁 |
| 4 | 旋转开关切换 | X7 | 高有效（主机档=1） | 立即全停，回空闲 | 切换完成自动恢复 |
| 5 | 上限位 | X4 | 高有效（触发=1） | 上升中=停止，下降中=强制下降 | 自动恢复 |
| 6 | 按钮 | X0/X1/X2/X5 | 低有效（按下=0，归一化为1） | 正常控制 | — |

---

## 九、关键设计要点（PLC 工程师视角）

1. **急停和光电是硬保护**：在任何状态下，只要 X3=1 或 X6=1，立即全停（Y0~Y5 全部输出低电平），无需等待当前动作完成
2. **光电报警需要人工介入**：不会因 X6=0 光电恢复就自动解除，必须后台发"解除报警"命令，防止遮挡物移走后误动作
3. **下降中的上限位是"加速下降"而非停止**：X4=1 时反而是卸荷下降（Y0=0 电机断，Y1/Y2/Y3 或 Y1/Y4/Y5 全开）
4. **下降中按锁定=强制下降**：X2=1 时电机立即断开（Y0=0），所有阀打开，快速卸载
5. **按钮释放即停止**：所有动作都是"按住才动作"，松手就停（除锁定保持外）
6. **旋转开关切换瞬间全停**：X7 状态变化时 Y0~Y5 全部输出低电平，防止带载切换主/子机
7. **所有按钮去抖 20ms，光电/旋转开关去抖 50ms**：避免抖动误触发
8. **电机到气阀的 200ms 延时**：保证电机先启动建立油压，再开气阀
9. **下降时电机保持 3s/1.5s**：让液压系统充分卸压后再断电机，防止冲击
10. **按钮低有效，安全类高有效**：按钮按下接通 GND（读到 0），急停/上限位/光电用 NC 常闭触点（触发时断开电路，读到 1）
