# 丝杆举升机接入与验收

## 已登记的平台型号

- 产品类型：`screw_lift`
- 显示名称：丝杆举升机
- 固件目录：`F407ZET6/GC-Screw_Lift`
- 编码器：双路，平台显示左高度、右高度和高度差
- MQTT 上行：`gaochang/lift/v1/devices/{chip_uid}/up`
- MQTT 下行：`gaochang/lift/v1/devices/{chip_uid}/down`

产品型号已写入 `product_configs`。该动作没有创建或修改个人用户、密码、角色或绑定记录。

## 登记一台实际设备

1. 刷入 `F407ZET6-SCREW-IOT-V1.0.1` 固件并让 DTU 连上 MQTT。
2. 从启动日志或 MCU UID 读出 24 位十六进制 `chip_uid`；不得自行编造 UID。
3. 管理后台“设备注册管理”新增记录，选择“丝杆举升机”，录入实际出厂编号、UID、绑定码；选择丝杆时会自动勾选“高度编码器”（服务端也会强制 `has_encoder=1`）。
4. 完成用户绑定后，设备上报会进入 `devices` 和 `device_status`；未登记 UID 的上报不会被平台当作受控设备接受。

首次绑定创建平台设备记录时，网站会按产品类型自动命名：丝杆00、丝杆01；大剪00；小剪00；超薄小剪00。各型号独立编号。固件遥测中的固定 `name` **不会**覆盖平台绑定名或人工改名。

发货前清除：丝杆固件无 `reset_usage`，平台对该型号仅清网站台账（`website_only`），不会下发未知命令。

## 高度验收

1. 静止时，设备详情显示两路编码器高度和差值。
2. 上升或下降过程中，首页卡片每 500 ms 更新左右高度；状态、方向、锁机和报警不应被高度帧重置。
3. 触发限位、碰撞或平衡报警后，确认高度仍能刷新且报警保持到设备安全逻辑清除。
4. 远程锁机/解锁仅在收到设备 `command_response` 后更新平台状态。

未连接实物控制板前，只能确认协议、数据库和网页数据链路；不能把软件回归等同于载荷下的机械安全验收。
