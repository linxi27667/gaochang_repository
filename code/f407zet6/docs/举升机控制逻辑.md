# 双柱举升机控制逻辑（两键控制）

## 一、IO表

| 信号 | 地址 | 类型 | 说明 |
|------|------|------|------|
| 上升按钮 | PE0 | 输入 | 常开、按下=0、内部上拉 |
| 下降按钮 | PE1 | 输入 | 常开、按下=0、内部上拉 |
| 左柱电源继电器 | PD8 | 输出 | 0=吸合、1=断开 |
| 右柱电源继电器 | PD9 | 输出 | 0=吸合、1=断开 |
| 上升方向继电器 | PD10 | 输出 | 0=吸合、1=断开 |
| 下降方向继电器 | PD11 | 输出 | 0=吸合、1=断开 |
| 运行指示灯 | PG2 | 输出 | 0=亮、1=灭，500ms闪烁 |
| 左编码器脉冲 | PE13 | 输入 | TIM1_CH3，下降沿，1脉冲=6mm |
| 右编码器脉冲 | PE14 | 输入 | TIM1_CH4，下降沿，1脉冲=6mm |

## 二、上电初始化

```
上电:
    所有继电器输出 = 1（全部断开，高电平）
    左柱脉冲计数 = 0
    右柱脉冲计数 = 0
    当前方向 = 停止
    告警状态 = 无
    上限位标志 = 0
    下限位标志 = 0
```

---

## 三、按键扫描（20ms周期）

```
// 两个按键独立状态机
// 状态转换: 空闲 → 消抖 → 确认按下 → 空闲

对于 上升键、下降键:
    读取IO电平
    
    如果 状态==空闲:
        如果 IO==0（按下）:
            状态 = 消抖
    
    如果 状态==消抖:
        如果 IO==0（仍按下）:
            按下标志 = 1      // 边沿，确认按下
            保持标志 = 1      // 持续为1，表示长按中
            状态 = 确认按下
            打印日志 "KeyX PRESS"
        否则:
            状态 = 空闲       // 抖动，忽略
    
    如果 状态==确认按下:
        如果 IO==1（松开）:
            保持标志 = 0      // 松手，长按结束
            按下标志 = 0
            状态 = 空闲
            打印日志 "KeyX RELEASE"

// 汇总
上升按钮_按住 = 上升键.保持标志
下降按钮_按住 = 下降键.保持标志
```

## 四、主控制循环（10ms周期）

```
// 执行顺序：告警 → 冲突 → 松手 → 启动 → 保护 → 日志

// ======== 第1步：告警处理 ========
如果 告警状态 != 无:
    如果 告警==碰撞 且 下降按钮_按住 且 非上升按钮_按住:
        清除告警           // 碰撞后只能下降退出
    否则 如果 上升按钮_按住 且 下降按钮_按住:
        清除告警           // 双键同按复位其他告警
    否则:
        跳出本次循环       // 告警中不响应操作

// ======== 第2步：双键冲突检测 ========
如果 上升按钮_按住 且 下降按钮_按住 且 当前方向!=停止:
    调用 全部停止
    当前方向 = 停止
    打印 "STOP (conflict)"

// ======== 第3步：松手停止 ========
如果 上升按钮_按住==0 且 当前方向==上升:
    调用 全部停止
    当前方向 = 停止
    打印 "STOP (up released)"

如果 下降按钮_按住==0 且 当前方向==下降:
    调用 全部停止
    当前方向 = 停止
    打印 "STOP (down released)"

// ======== 第4步：按下启动 ========
如果 上升按钮_按住 且 非下降按钮_按住 且 当前方向==停止:
    如果 已到上限位: 跳过
    调用 双柱同时启动(上升)
    当前方向 = 上升
    清除下限位标志
    打印 "Status: UP"

如果 下降按钮_按住 且 非上升按钮_按住 且 当前方向==停止:
    如果 已到下限位: 跳过
    调用 双柱同时启动(下降)
    当前方向 = 下降
    清除上限位标志
    打印 "Status: DOWN"

// ======== 第5步：运行中保护 ========
如果 当前方向 != 停止:
    调用 平衡检测
    调用 上限位检测
    调用 下限位检测

// ======== 第6步：实时高度 ========
如果 当前方向 != 停止:
    打印 left=左柱高度mm right=右柱高度mm   // 每10ms

// ======== 第7步：心跳 ========
每5秒打印一次:
    按键任务: key_state IDLE/UP/DOWN
    控制任务: heartbeat STOP/UP/DOWN left=xxmm right=xxmm
    安全任务: heartbeat alarm=x stall=x upper=x lower=x

// ======== 第8步：LED ========
每500ms翻转一次运行灯
```

## 五、电机启动/停止时序

```
// ========== 双柱同时启动(方向) ==========
// 铁律：先合方向继电器 → 延时 → 再合电源继电器

启动(方向):
    如果 告警!=无: 不执行
    如果 方向==上升 且 已到上限位: 不执行
    如果 方向==下降 且 已到下限位: 不执行
    
    如果 方向==上升:
        下降继电器 = 断开          // 确保对向断开
        上升继电器 = 吸合          // ① 先合方向
        延时 20ms                 // 方向继电器触点稳定
        左电源继电器 = 吸合        // ② 再合电源
        右电源继电器 = 吸合
    
    如果 方向==下降:
        上升继电器 = 断开
        下降继电器 = 吸合
        延时 20ms
        左电源继电器 = 吸合
        右电源继电器 = 吸合
    
    左柱状态 = 运行中
    右柱状态 = 运行中


// ========== 全部停止 ==========
// 铁律：先断方向 → 延时 → 再断电源

全部停止():
    上升继电器 = 断开          // ① 先断方向
    下降继电器 = 断开
    延时 10ms                 // 灭弧，方向触点无电流断开
    左电源继电器 = 断开        // ② 再断电源
    右电源继电器 = 断开
    
    左柱状态 = 停止
    右柱状态 = 停止


// ========== 单柱暂停（平衡同步用） ==========
// 只断电源，不断方向！方向继电器保持吸合

暂停(柱号):
    该柱电源继电器 = 断开
    该柱状态 = 等待平衡


// ========== 紧急停止 ==========
// 四路同时断开，不等延时

紧急停止():
    上升继电器 = 断开
    下降继电器 = 断开
    左电源继电器 = 断开
    右电源继电器 = 断开
    左柱状态 = 停止
    右柱状态 = 停止
```

## 六、编码器脉冲计数（硬件中断）

```
// TIM1通道3 = PE13下降沿 → 左柱
// TIM1通道4 = PE14下降沿 → 右柱
// 在 tim.c 的 HAL_TIM_IC_CaptureCallback 中处理

中断(通道):
    如果 该柱_计数允许 == 0: 忽略
    
    如果 当前方向 == 上升:
        该柱_脉冲计数 = 该柱_脉冲计数 + 1
    如果 当前方向 == 下降:
        该柱_脉冲计数 = 该柱_脉冲计数 - 1
    
    更新该柱最后脉冲时间戳（堵转检测用）
```

## 七、双柱平衡算法（10ms周期）

```
// 允差 = 4个脉冲（24mm）
// 原则：暂停跑得太快的那一侧，等慢的一侧追上
// 下降时计数递减，所以"计数小"=跑得快，需要反过来判断

平衡检测():
    左计数 = 左柱_脉冲计数
    右计数 = 右柱_脉冲计数
    
    // ---- 判断谁更快 ----
    如果 当前方向 == 上升:
        // 上升计数递增 → 计数大=跑得快
        如果 左计数 > 右计数:
            差值 = 左计数 - 右计数
            较快的柱 = 左柱
        否则:
            差值 = 右计数 - 左计数
            较快的柱 = 右柱
    否则（下降）:
        // 下降计数递减 → 计数小=跑得快（降得更多）
        如果 左计数 < 右计数:
            差值 = 右计数 - 左计数
            较快的柱 = 左柱
        否则:
            差值 = 左计数 - 右计数
            较快的柱 = 右柱
    
    // ---- 超差 → 暂停（阈值=4） ----
    如果 差值 > 4:
        如果 较快的柱_状态 == 运行中:
            暂停(较快的柱)         // 只断电源，方向继电器保持
            较快的柱_状态 = 等待平衡
            记录等待开始时间
            打印 "PAUSE col=X diff=X"
    
    // ---- 追上 → 恢复（差值≤1才恢复，有滞回区间） ----
    如果 差值 <= 1:
        对每个柱:
            如果 该柱_状态 == 等待平衡:
                启动(该柱, 当前方向)   // 重新吸合电源继电器
                该柱_状态 = 运行中
                打印 "RESUME col=X diff=X"
    // 差值在2~4之间不做操作，防止继电器频繁通断
    
    // ---- 等待超时 10秒 → 告警 ----
    对每个柱:
        如果 该柱_状态 == 等待平衡:
            如果 (当前时间 - 等待开始时间) > 10秒:
                全部停止()
                告警 = 平衡超时
```

## 八、安全保护（10ms周期）

```
// ========== 堵转检测 ==========
堵转检测():
    对每个柱:
        如果 该柱_状态 != 运行中: 跳过
        如果 (当前时间 - 最后脉冲时间) > 2秒:
            全部停止()
            告警 = 堵转
            打印 "Stall! col=X"

// ========== 上限位 ==========
上限位检测():
    如果 当前方向 != 上升: 跳过
    如果 左计数 >= 166 或 右计数 >= 166:    // 166脉冲×6mm = 1000mm
        全部停止()
        当前方向 = 停止
        已到上限位 = 1
        打印 "Top reached"

// ========== 下限位 ==========
下限位检测():
    如果 当前方向 != 下降: 跳过
    如果 左计数 <= 0 或 右计数 <= 0:
        全部停止()
        当前方向 = 停止
        左计数 = 0
        右计数 = 0
        已到下限位 = 1
        打印 "Bottom reached"

// ========== 告警清除 ==========
告警处理():
    如果 告警==碰撞 且 仅下降键按住:
        清除告警，只能下降退出碰撞
    如果 双键同按:
        清除告警（堵转/平衡超时可双键复位）
```

## 九、操作速查

| 操作 | 效果 |
|------|------|
| 按住上升 | 双柱上升（到1000mm自动停） |
| 按住下降 | 双柱下降（到0自动停） |
| 松手 | 立即停止 |
| 运动中双键同按 | 立即停止 |
| 告警中双键同按 | 清除告警 |
| 碰撞告警中单按下降 | 清除告警并下降退出 |

## 十、状态总览

| 场景 | 上升继电器 | 下降继电器 | 左电源 | 右电源 | 左计数 | 右计数 |
|------|-----------|-----------|--------|--------|--------|--------|
| 待机 | OFF | OFF | OFF | OFF | 保持 | 保持 |
| 上升中 | ON | OFF | ON | ON | ++ | ++ |
| 下降中 | OFF | ON | ON | ON | -- | -- |
| 平衡暂停(上升) | ON | OFF | **OFF** | ON | 不变 | ++ |
| 平衡暂停(下降) | OFF | ON | ON | **OFF** | -- | 不变 |
| 堵转告警 | OFF | OFF | OFF | OFF | 保持 | 保持 |
| 上限位 | OFF | OFF | OFF | OFF | ≤166 | ≤166 |
| 下限位 | OFF | OFF | OFF | OFF | 0 | 0 |

---

**操作铁律两句：启机先合方向后合电源，停机先断方向后断电源。平衡时只切电源不断方向。**
