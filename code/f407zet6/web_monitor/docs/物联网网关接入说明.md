# 物联网网关接入说明

## 1. 串口接入

MCU 使用 USART3 与 TAS-LTE-892D_s4 DTU 通信：

- 接收：DMA + 空闲中断 + FIFO
- 发送：TX FIFO + DMA 非阻塞队列
- 回调：标准 HAL 回调统一放在 `Core/Src/usart.c`

DTU 进入命令模式流程：

```text
MCU -> +++
DTU -> a
MCU -> a
DTU -> +ok
MCU -> AT 指令配置 MQTT
```

## 2. MQTT 配置

默认 Broker：

```text
mqtt://8.134.167.240:1883
```

默认无用户名密码，固件已预留账号密码字段。

## 3. MQTT 主题

当前 F407 网关：

```text
遥测主题: gaochang/lift/f407zet6/telemetry
命令主题: gaochang/lift/f407zet6/command
状态主题: gaochang/lift/f407zet6/status
```

多设备扩展时将 `f407zet6` 替换为网关编号，例如 `station02`。

## 5. 远程命令 JSON

命令主题发布：

```json
{
  "type": "command",
  "cmd": "lock",
  "command": "lock",
  "device": "gaochang_lift_f407zet6",
  "account": "admin",
  "password": "",
  "ts": 1780470000000
}
```

支持命令：

| cmd | 说明 |
| --- | --- |
| `get_status` | 状态查询 |
| `lock` | 锁机，MCU 本地立即停止电机 |
| `unlock` | 解锁 |
| `admin_enter` | 管理员模式认证 |
| `admin_exit` | 退出管理员模式 |
| `fault_clear` | 故障确认/解除 |
| `maintenance_done` | 保养完成 |
| `admin_jog` | 管理员点动调平 |

管理中心后端会根据登录账号角色进行权限校验，并将真实登录账号写入操作日志。前端传入的 `account` 字段不作为权限依据。

管理员点动示例：

```json
{
  "type": "command",
  "cmd": "admin_jog",
  "device": "gaochang_lift_f407zet6",
  "account": "admin",
  "password": "123456",
  "column": "left",
  "direction": "up",
  "duration_ms": 300
}
```

## 6. 安全边界

网络指令只负责管理动作。急停、限位、水平失衡、堵转等安全动作由设备本地控制系统优先闭环处理。网络异常时设备仍可本地停机和报警。
