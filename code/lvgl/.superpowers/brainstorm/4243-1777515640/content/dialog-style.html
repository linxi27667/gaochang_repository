全屏键盘输入

点击输入框后，键盘从底部滑出占据半屏，类似iOS键盘交互。适合需要频繁输入的场景（设置参数、密码等）。

建议组合：
• 数值输入（高度、密码等） → 全屏键盘
• ON/OFF切换、语言选择 → Action Sheet
• 确认操作（一键调平、删除用户） → Alert
