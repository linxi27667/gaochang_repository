大按钮网格风格

2×3大按钮网格，每个按钮显示图标+名称+当前值。适合触控操作，与主页风格统一。点击后弹出设置弹窗。

建议：
• 控制页：大按钮网格（与主页可视化风格统一，触控友好）
• 设置页：iOS列表风格（信息密度高，适合WiFi、语言、亮度等详细设置）
• 用户页：iOS列表风格（登录表单、管理员列表）
