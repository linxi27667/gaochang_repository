# 高昌举升机 HMI 项目文档

## 项目概述

**名称**：高昌丝杆举升机 HMI 系统 - 方案二
**文件**：`方案二.html`
**分辨率**：1024x600（工业触控屏标准分辨率）
**目标框架**：LVGL v9（当前为 HTML/CSS/JS 原型预览）
**应用场景**：汽车维修车间双立柱丝杆举升机的工业触控操作界面

## 三、功能模块

### 3.1 上电启动登录

- 全屏覆盖，深色背景，居中登录卡片
- 默认账号：`admin` / `123456`
- 登录错误时红色文字提示
- 登录成功后进入主界面，启动数据模拟和时钟

### 3.2 数据看板

- **实时数据模拟**：每 3 秒随机更新 H1、H2 高度值（1800-1900mm 范围）
- **高度差计算**：`|H1 - H2|`，根据差值判断状态：
  - `<= 10mm`：正常（绿色）
  - `<= 20mm`：警告（橙色）
  - `> 20mm`：超限（红色）
- **报警模拟**：5% 概率触发异常代码
- **状态列表**：系统状态、联机状态、运行模式、今日作业次数
- **快捷按钮**：点击弹出控制值输入弹窗

### 3.3 控制面板

- 6 个大按钮（220x140px），flex-wrap 居中布局
- 每个按钮：渐变图标背景（荧光绿）+ 文字
- 点击按钮弹出控制值输入弹窗
- "一键调平"按钮走确认弹窗流程（需二次确认）

### 3.4 系统设置

- **系统语言**：下拉选择简体中文 / English
- **屏幕亮度**：可点击编辑，弹出页面底部触控键盘
- **报警阈值**：可点击编辑，弹出页面底部触控键盘
- **系统版本**：V1.2.0（只读）
- **设备序列号**：GC-2024-00128（只读）
- **MAC地址**：A1:B2:C3:D4:E5:F6（只读）
- **管理员管理**：弹窗显示管理员表格，支持添加/删除

### 3.5 关于页面

- 系统名称、型号信息
- 产品简介
- 6 个核心功能卡片（2x2 网格）
- 固件版本和序列号

### 3.6 管理员管理

- 弹窗表格形式展示已添加管理员
- 默认主管理员 `admin`（不可删除）
- 可添加新管理员（用户名 + 密码）
- 重复用户名检测
- 删除普通管理员需确认

### 3.7 控制值输入弹窗

- 点击控制面板或看板快捷按钮时弹出
- 弹窗内集成触控键盘
- 显示标题、当前值（大字）、单位
- 键盘：数字 0-9、负号、小数点、退格、清空
- 底部"取消"和"应用"按钮

### 3.8 页面底部触控键盘（模拟 LVGL lv_keyboard）

- 全屏宽度，底部滑入动画
- 用于设置面板的数值编辑
- 4行数字键 + 工具行（退格、清空、应用、关闭）
- 关闭时恢复页面布局

### 3.9 确认弹窗（Msgbox）

- 用于危险操作的二次确认（如"一键调平"）
- 标题 + 描述文字 + 取消/确认按钮

## 六、技术架构

### 前端架构

- **单文件结构**：所有 HTML + CSS + JS 整合在 `方案二.html` 中
- **无外部框架依赖**（除 FontAwesome CDN）
- **i18n 字典模式**：中英文双语，通过 `t(key)` 函数切换
- **组件化渲染**：`render_dashboard()`、`render_control_panel()`、`render_settings_panel()` 分别负责各页面

### 状态管理

- 全局变量 `sim_data`：模拟传感器数据
- 全局变量 `current_page`：当前页面名
- 全局变量 `admin_list`：管理员列表（内存）
- 全局变量 `kb_callback` / `kb_current_value`：页面级键盘状态
- 全局变量 `ctrl_dialog_callback` / `ctrl_dialog_unit`：控制弹窗状态

### 动画效果

- 页面切换：`translateX(40px)` → `translateX(0)` + 透明度渐变（350ms）
- 登录弹窗：`scale(0.95) translateY(10px)` → `scale(1)`（400ms）
- 确认弹窗：同登录弹窗（300ms）
- 触控键盘：`translateY(100%)` → `translateY(0)`（200ms）
- 状态指示灯：`pulse` 动画（2s 无限循环）

### 定时器

- 时钟更新：每 1 秒
- 数据模拟：每 3 秒

## 八、LVGL v9 移植指引

本项目当前为 HTML/CSS/JS 原型，目标为移植到嵌入式 LVGL v9 C 语言框架。

### 对应关系

| HTML 元素 | LVGL v9 组件 | 说明 |
|-----------|-------------|------|
| `.screen` | `lv_obj_create(lv_screen_active())` | 根容器 1024x600 |
| `.sidebar` | `lv_obj` flex 布局 | 左侧导航 |
| `.nav-btn` | `lv_btn` + `lv_label` | 导航按钮 |
| `.lvgl-symbol` | `lv_label` + `LV_SYMBOL_*` | Unicode 符号（原生支持） |
| `.dashboard-grid` | `lv_grid` (LVGL 原生 Grid) | 6 卡片布局 |
| `.card` | `lv_obj` + `lv_obj_set_style_bg_color` | 卡片容器 |
| `.control-btn` | `lv_btn` | 快捷按钮 |
| `.app-btn` | `lv_btn` | 控制面板大按钮 |
| `.settings-item` | `lv_obj` flex | 设置项 |
| `.touch-keyboard` | `lv_keyboard` | 原生键盘组件 |
| `.ctrl_overlay` | `lv_msgbox` 或自定义弹窗 | 控制值输入 |
| `.msgbox-overlay` | `lv_msgbox` | 确认弹窗 |
| `.boot-overlay` | `lv_obj` 全屏覆盖 | 登录界面 |

### 字体

- LVGL v9 原生支持 Unicode 符号，无需 FontAwesome
- 使用 `LV_SYMBOL_HOME`、`LV_SYMBOL_EDIT`、`LV_SYMBOL_SETTINGS`、`LV_SYMBOL_QUESTION` 等内置符号
- 中文需要额外字体文件（如 `SourceHanSansSC`）

### 布局

- LVGL v9 的 `lv_grid` 完全支持 CSS Grid 的列/行跨度功能
- `grid_template_columns: repeat(4, 1fr)` → `lv_grid_set_column_dsc`
- `grid_column: 1 / 3` → `LV_GRID_ALIGN_STRETCH` + span 参数
