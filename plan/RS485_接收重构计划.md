# RS485 接收重构：切换到 HAL_UARTEx_RxEventCallback

## Context

当前 `bsp_rs485.c` 使用手动 IDLE 中断处理（`RS485_IRQHandler`），需要手动计算 DMA counter、手动维护 head 指针、手动处理溢出。存在 2 个竞态 bug：

1. `RS485_Receive` 读 head/tail 时没有关中断保护
2. `RS485_IRQHandler` 溢出处理直接改 rx_tail，与任务上下文竞态

切换到 ST 官方推荐的 `HAL_UARTEx_RxEventCallback` 后：
- HAL 自动计算接收字节数（Size 参数），无需手动算 DMA counter
- DMA 保持 Circular 模式不变，HAL 内部自动处理循环计数
- 自然消除上述 2 个竞态 bug（不再需要手动维护 head）

## 方案：DMA Circular + HAL_UARTEx_RxEventCallback

### 核心变化

| 项目 | 当前 | 新方案 |
|------|------|--------|
| DMA RX 模式 | Circular | **Circular（不变）** |
| IDLE 检测 | 手动检查 IDLE 标志 | HAL 自动检测 |
| 接收数据长度 | `__HAL_DMA_GET_COUNTER` 手动算 | Size 参数直接可用 |
| 溢出处理 | ISR 中改 rx_tail（有 bug） | 应用层读数据时处理 |
| USART2_IRQHandler | 调用 HAL + 手动 RS485_IRQHandler | 只调用 HAL |

### 数据流变化

**当前**：
```
USART2_IRQHandler
  → HAL_UART_IRQHandler(&huart2)
  → RS485_IRQHandler(&rs485_handle)   // 手动算 DMA counter → 更新 head
```

**新方案**：
```
USART2_IRQHandler
  → HAL_UART_IRQHandler(&huart2)
      → 内部检测 IDLE
      → 调用 HAL_UARTEx_RxEventCallback(huart, Size)
          → 回调中更新 rx_head += Size
          → 无需重启 DMA（Circular 模式自动继续）
```

## 修改文件清单

### 1. `BSP/Inc/bsp_rs485.h`

- 删除 `RS485_IRQHandler` 声明（不再需要在 stm32f4xx_it.c 中调用）
- `rx_idle_callback` 参数保持 `(void *arg, uint16_t new_data_len)` 不变

### 2. `BSP/Src/bsp_rs485.c`

#### RS485_Init（不变）
```c
HAL_StatusTypeDef RS485_Init(RS485_HandleTypeDef *hrs485)
{
    // 创建信号量 ...（不变）

    // DMA 启动（Circular 模式，与当前一致）
    HAL_StatusTypeDef ret = HAL_UART_Receive_DMA(hrs485->huart,
                                                  hrs485->rx_buf,
                                                  hrs485->rx_buf_size);
    if (ret != HAL_OK) return ret;

    // 使能 IDLE 中断（HAL 内部会检测并调用 RxEventCallback）

    // 初始化状态（不变）
    hrs485->rx_head = 0;
    hrs485->rx_tail = 0;
    // ...
}
```

#### 删除 RS485_IRQHandler 函数
整个函数删除，不再需要手动算 DMA counter。

#### 新增 HAL_UARTEx_RxEventCallback
```c
void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef *huart, uint16_t Size)
{
    if (huart->Instance == RS485_UART) {
        /* Size = 自上次回调以来 DMA 接收到的字节数
         * Circular 模式下 HAL 内部自动计算，无需手动处理 */
        uint16_t old_head = rs485_handle.rx_head;
        uint16_t new_head = (old_head + Size) % rs485_handle.rx_buf_size;

        /* 溢出检测：新 head 追上 tail → 丢弃最旧数据 */
        if (Size >= rs485_handle.rx_buf_size) {
            rs485_handle.rx_tail = (new_head + 1) % rs485_handle.rx_buf_size;
        }

        rs485_handle.rx_head = new_head;

        if (rs485_handle.rx_idle_callback)
            rs485_handle.rx_idle_callback(&rs485_handle, Size);

        /* Circular 模式无需重启 DMA，自动继续接收 */
    }
}
```

#### RS485_Receive 简化（修复 Bug 1）
```c
uint16_t RS485_Receive(RS485_HandleTypeDef *hrs485,
                       uint8_t *buf, uint16_t max_len)
{
    /* 读 head 需要关中断保护（ISR 可能更新 head） */
    uint32_t primask = __get_PRIMASK();
    __disable_irq();
    uint16_t head = hrs485->rx_head;
    __set_PRIMASK(primask);

    uint16_t tail = hrs485->rx_tail;  // tail 只在任务上下文修改，无需保护
    uint16_t size = hrs485->rx_buf_size;

    uint16_t available = (head - tail + size) % size;
    if (available == 0) return 0;

    uint16_t to_read = (available > max_len) ? max_len : available;

    // 绕回拷贝 ...（不变）

    hrs485->rx_tail = (tail + to_read) % size;
    return to_read;
}
```

#### HAL_UART_ErrorCallback（自愈逻辑不变）
```c
void HAL_UART_ErrorCallback(UART_HandleTypeDef *huart)
{
    if (huart->Instance == RS485_UART) {
        // 错误统计 ...（不变）
        // 清除错误标志 ...（不变）

        /* 重启 DMA 接收（自愈） */
        HAL_UART_AbortReceive(huart);
        HAL_UART_Receive_DMA(huart,
                             rs485_handle.rx_buf,
                             rs485_handle.rx_buf_size);
        __HAL_UART_ENABLE_IT(huart, UART_IT_IDLE);
    }
}
```

### 3. `Core/Src/usart.c`

**不需要修改** — DMA RX 保持 `DMA_CIRCULAR`（line 199），无需改动。

### 4. `Core/Src/stm32f4xx_it.c`

- `USART2_IRQHandler` 中**删除** `RS485_IRQHandler(&rs485_handle);` 调用（line 294）
- 保留 `HAL_UART_IRQHandler(&huart2);`（HAL 内部会调用 RxEventCallback）

## Bug 修复效果

| Bug | 修复方式 |
|-----|----------|
| RS485_Receive head/tail 竞态 | head 只在 ISR 更新，读取时关中断保护；tail 只在任务修改，无需保护 |
| RS485_IRQHandler 溢出改 tail | 函数删除，溢出处理移到 RxEventCallback 中 |

## 注意事项

### 回调函数重复定义问题
`HAL_UART_TxCpltCallback` 和 `HAL_UART_ErrorCallback` 在 `bsp_uart_dma.c` 和 `bsp_rs485.c` 中都有定义。需要确认：
- 条件编译是否保证只有一个生效
- 或者合并为统一的回调，通过 `huart->Instance` 分发

### 不需要改 DMA 模式
`HAL_UARTEx_RxEventCallback` 在 Circular 模式下完全可用，HAL 内部自动计算 Size 参数。无需改为 Normal 模式。
