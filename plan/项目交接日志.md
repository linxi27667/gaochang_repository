## 一、项目概述

- **MCU**: STM32F407VET6 (Cortex-M4, 168MHz)
- **RTOS**: FreeRTOS (CMSIS-OS v1 wrapper)
- **Flash**: W25Q80 (1MB, SPI1)
- **日志**: EasyLogger (elog) + SEGGER RTT
- **通信**: RS485 (USART2, 自动方向模块)
- **工具链**: MDK-ARM (Keil v5) / CMake + GCC
- **功能**: 双柱丝杆举升机的升降控制、平衡同步、安全保护

## 三、引脚分配表（2026-05-08 最终版）

所有引脚宏定义在对应的 `.h` 文件中，修改接线只需改宏。

### 3.1 编码器输入（TIM2 输入捕获）

| 功能 | 引脚 | CubeMX 配置 | 宏定义位置 |

### 3.2 电机输出（4 继电器）

**全部低电平吸合 (RELAY_ON = GPIO_PIN_RESET)。**  
**上升/下降继电器为两柱共享，仅总开关闭合的电机才受方向继电器控制。**

| 继电器 | 引脚 | 宏名 | 作用范围 |
|--------|------|------|---------|
| 左柱主接触器 | **PC0** | `COL_LEFT_MAIN_PORT/PIN` | 仅左柱 |
| 右柱主接触器 | **PC4** | `COL_RIGHT_MAIN_PORT/PIN` | 仅右柱 |
| 上升继电器 | **PC2** | `RELAY_UP_PORT/PIN` | **两柱共享** |
| 下降继电器 | **PC5** | `RELAY_DOWN_PORT/PIN` | **两柱共享** |

> ⚠️ **互斥规则**：PC2 和 PC5 绝对不能同时拉低——会造成电源短路。  
> 代码已在 `Motor_Start` 中保证：开新方向前先关反向继电器。

## 四、继电器控制逻辑（核心章节，务必读懂）

### 4.1 设计原则

```
通电（先铺路，再通电）：
  方向继电器先吸合 → 等 20ms 稳定 → 主接触器吸合（扛电流冲击）
  
断电（先断电，再换向）：
  主接触器先断 → 等 10ms 灭弧 → 方向继电器可安全换向（无电不打火花）
```

**为什么这样设计？**
- 方向继电器触点小，不能扛电机启动/断开的大电流电弧
- 主接触器是工业接触器，专门扛电弧
- "先铺好路再通电"让主接触器独自承受所有冲击
- "先断电再换向"保证方向继电器在无电流时切换，延长寿命

### 4.2 六个电机控制函数

#### Motor_Start(column_index, DIR_UP) — 启动单柱上升

```
PC5=HIGH(关DOWN) → PC2=LOW(开UP) → 等20ms → PC(col)=LOW(开总开关)
```

#### Motor_Start(column_index, DIR_DOWN) — 启动单柱下降

```
PC2=HIGH(关UP) → PC5=LOW(开DOWN) → 等20ms → PC(col)=LOW(开总开关)
```

#### Motor_Start_All(DIR_UP) — 双柱同升

```
PC5=HIGH(关DOWN) → PC2=LOW(开UP) → 等20ms → PC0=LOW + PC4=LOW(两个总开关)
```

#### Motor_Start_All(DIR_DOWN) — 双柱同降

```
PC2=HIGH(关UP) → PC5=LOW(开DOWN) → 等20ms → PC0=LOW + PC4=LOW
```

#### Motor_Stop(col) / Motor_Pause(col) — 停/暂停单柱

```
PC(col)=HIGH(关总开关)
// 不动方向继电器！另一柱可能还在用
```

| 函数 | 延时 | 用途 |
|------|------|------|
| `Motor_Stop(col)` | 等 10ms 灭弧 | 用户松手停止 |
| `Motor_Pause(col)` | 无延时 | 平衡算法暂停快柱 |

#### Motor_Stop_All() — 停止全部

```
PC0=HIGH + PC4=HIGH(关两个总开关) → 等10ms灭弧 → PC2=HIGH + PC5=HIGH(关方向)
```

#### Motor_Stop_All_Immediate() — 紧急停机（ISR 安全）

```
PC0/PC2/PC4/PC5 全部拉高，无延时
// 防碰杆/堵转等紧急情况在中断中直接调用
```

### 4.3 为什么 Motor_Stop 和 Motor_Pause 不能关方向继电器？

如果正在双柱同升，有柱 A 跑得快被暂停了：
- 如果关方向继电器（PC2=HIGH）→ 柱 B 也失去方向 → 柱 B 也停了！
- 正确做法：只关柱 A 的总开关（PC0=HIGH），方向继电器保持 PC2=LOW → 柱 B 继续升

### 4.4 继电器电平约定

```c
#define RELAY_ON   GPIO_PIN_RESET  // LOW = 吸合
#define RELAY_OFF  GPIO_PIN_SET    // HIGH = 断开
```

CubeMX 中 PC0/PC2/PC4/PC5 初始化为 **GPIO_Output PP, High**（上电默认全关）。  
失效安全：MCU 死机 → GPIO 高阻 → 光耦关断 → 4 个继电器全断 → 电机停机。

## 五、RS485 通信驱动（新增 2026-05-08）

### 5.1 架构

```
APP 层 (app_rs485.c)
  │  配置: USART2 / 115200 / 256B / 100ms
  │  调用: UartDMA_Init / UartDMA_Send / UartDMA_Receive
  │
  ▼
BSP 层 (bsp_uart_dma.c)
  └── 不知 RS485，只知道"给一个 UART+DMA 句柄，收发数据"

Core 层 ──提供──→ usart.c (huart2, hdma_usart2_rx/tx)
                stm32f4xx_it.c (USART2_IRQHandler → RS485_IRQHandler → UartDMA_IRQHandler)
```

### 5.2 数据结构

```c
// 256 字节环形缓冲区 + DMA 循环模式
// rx_head: DMA 写入位置（IDLE 中断更新）
// rx_tail: 任务读取位置（RS485_Receive 更新）
// 有效可读字节 = (head - tail + 256) % 256

// FreeRTOS 同步
// tx_mutex:    互斥量，同一时刻只有一个任务能发
// tx_done_sem: 二值信号量，发送完成通知
```

### 5.3 环形缓冲区溢出保护

浪费 1 字节空间，保证 `head == tail` 永远只代表"空"。
每次 IDLE 中断检测本帧长度是否超过收帧前剩余空间：

```c
frame_len = (new_head - old_head) % 256   // 本帧收了多长
free_space = (tail - old_head - 1) % 256  // 收帧前还剩多少空间

if (frame_len > free_space) {
    tail = new_head;  // 溢出，丢弃全部旧数据，重新开始
}
```

### 5.4 发送流程

```
RS485_Transmit():
  1. 获取互斥量 tx_mutex (最多等 1 秒)
  2. 清空残留信号量
  3. 启动 DMA 发送 (自动方向模块硬件切换 DE)
  4. 等待二值信号量 (超时 100ms → HAL_UART_AbortTransmit 自愈)
  5. 释放互斥量
```

### 5.5 错误自愈

`HAL_UART_ErrorCallback`：检测 ORE/FE/NE 错误 → 清标志 → Abort + 重启 DMA 接收 + 重新使能 IDLE 中断。

### 5.6 USART2 关键变量（定义在 usart.c，extern 在 main.h）

```c
UART_HandleTypeDef huart2;              // USART2 句柄
DMA_HandleTypeDef hdma_usart2_rx;      // DMA1_Stream5, Circular
DMA_HandleTypeDef hdma_usart2_tx;      // DMA1_Stream6, Normal
```

### 5.7 测试任务

`RS485_Echo_Task`（freertos.c，优先级 Normal+2，栈 256 字）：
- 每 10ms 轮询环形缓冲区
- 有数据就原样回传
- 每 2 秒自动发送 `RS485 self-test OK\r\n`

## 六、CubeMX 配置

### 6.1 TIM2（编码器输入捕获）
- PA0 → TIM2_CH1, PA1 → TIM2_CH2
- Prescaler: 80-1 (1MHz), Period: 65535-1
- NVIC: TIM2 global interrupt, Preempt=0, Sub=0

### 6.2 电机继电器 GPIO (PC0/PC2/PC4/PC5)
- 全部 GPIO_Output PP, **High**, No pull
- 默认 High = 继电器全关（安全态）

### 6.3 USART2（RS485）
- Mode: Asynchronous, 115200, 8N1, No parity, No flow control
- DMA: Stream5 RX (Periph→Mem, **Circular**), Stream6 TX (Mem→Periph, Normal)
- NVIC: USART2 + DMA1_Stream5 + DMA1_Stream6

### 6.4 GPIO（其他）
- PB8: GPIO_Output PP, Low (蜂鸣器)
- PB0-PB2: GPIO_EXTI (安全输入)
- PB12-PB15: GPIO_Input, Pull-up (按键)

## 九、核心模块速查

### motor.h/c — 电机控制
- **文件**: `APP/Inc/motor.h` (66行), `APP/Src/motor.c` (149行)
- **4 继电器**: PC0 左总、PC2 上升、PC4 右总、PC5 下降
- **时序原则**: 通电 = 方向先 → 主开关后；断电 = 主开关先 → 方向后
- **关键函数**: Motor_Start, Motor_Start_All, Motor_Stop, Motor_Pause, Motor_Stop_All, Motor_Stop_All_Immediate

### bsp_uart_dma.h/c — BSP 层 UART+DMA 通用驱动
- **文件**: `BSP/Inc/bsp_uart_dma.h` (38行), `BSP/Src/bsp_uart_dma.c` (164行)
- **职责**: 纯硬件抽象 — UART DMA 收发、环形缓冲区、IDLE 中断、FreeRTOS 同步原语
- **不包含**: 任何 RS485/协议相关的宏或逻辑

### app_rs485.h/c — APP 层 RS485 协议封装
- **文件**: `APP/Inc/app_rs485.h` (22行), `APP/Src/app_rs485.c` (68行)
- **职责**: 协议配置 (缓冲区/超时/波特率)、日志输出、委托调用 BSP 层

### key.h/c — 按键 + 蜂鸣器
- **文件**: `APP/Inc/key.h` (65行), `APP/Src/key.c` (100行)
- 4 按键状态机消抖（IDLE → DEBOUNCE → CONFIRMED → IDLE）
- `f_push`(单次触发，用于停止/确认键) / `f_hold`(持续有效，用于上升/下降键)
- 蜂鸣器支持 Beep(ms) 定时自动关闭

### encoder.h/c — 脉冲捕获
- **文件**: `APP/Inc/encoder.h` (13行), `APP/Src/encoder.c` (54行)
- TIM2_CH1(PA0) + TIM2_CH2(PA1) 输入捕获 ISR 中 `pulse_count++`
- 原子读取: `__disable_irq / __set_PRIMASK` 保护
- 高度换算: `height_mm = pulse_count × g_config.screw_lead_mm`

### balance.h/c — 双柱平衡
- **文件**: `APP/Inc/balance.h`, `APP/Src/balance.c` (84行)
- 每 10ms 计算 `|c0 - c1|`，超出允差暂停快柱，差值回到允差内恢复
- 超时 → 全部停机 + ALARM_BALANCE_TIMEOUT
- 暂停用 Motor_Pause: 只断总开关，保留方向继电器

### safety.h/c — 安全保护
- **文件**: `APP/Inc/safety.h` (49行), `APP/Src/safety.c` (167行)
- 保护类型: 上限位/下限位/防碰杆/堵转/二次下降/告警复位

### app_w25qxx.h/c — Flash 存储
- **文件**: `APP/Inc/app_w25qxx.h`, `APP/Src/app_w25qxx.c` (255行)
- W25Q80 通过 SPI1 访问，三层架构: APP→BSP→BSP(spi)
- 高度存储在 Sector 2 (0x2000)，每 5 秒保存一次
- 原子读取（关中断保护）+ CRC32 校验
